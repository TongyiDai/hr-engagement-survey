# 从洞察到行动

调研最常见的失败不是问卷设计不好，而是**收集完反馈就没有下文**。员工看不到任何改变，下一次就不会认真填。所以分析报告的终点不是分数，而是一份能落地、可追责的行动计划。

核心原则：**宣布结果时，同时宣布要做什么。**

## 行动规划五步

### 1. 排优先级
不要试图一次解决所有短板。按两个维度筛：
- **影响大**：哪个短板对整体敬业度拉动最大（看维度得分和开放题提及频次）。
- **可改**：哪些能真正动手改，而不是空喊。
组合「30 天能见效的快赢」和「需要长期投入的大事」，先各挑一两个。

### 2. 定责任人和团队
每个改进事项指定一个负责人，配一个跨职能小组，尽量纳入受影响的员工。写清楚：要解决什么问题、做到什么算完成、什么时间点。

### 3. 找根因、设计方案
别只治标。先弄清短板背后的根因（如「晋升不透明」背后可能是没有能力模型），再设计方案，方案先在小范围试点更稳。

### 4. 带追责地执行
明确负责人和时间线，定期检查进度，到里程碑就同步，需要时调整。

### 5. 衡量效果
定好「怎么算见效」的指标，约定在下一次脉冲或年度调研时复测。把「改了什么、哪些见效、哪些没见效」如实同步。

## 行动计划模板

```
行动计划：<主题，如 职业发展通道>

问题
- 得分最低的维度：<维度 得分>
- 关键题目：<题目 得分>
- 开放题提及频次：<次数>

根因
- <根因 1>
- <根因 2>

方案（可拆成多条，各有负责人和时间线）
1. <举措>（负责人：<> | 周期：<> | 成功指标：<>）
2. ...

时间线
- 第 1 月：<>
- 第 3 月：<>
- 6 个月复盘：<>

成功指标（下次调研复测）
- <维度> 从 <现值> → <目标>
- 参与率 / 满意度 / 覆盖率 <目标>

沟通
- 结果公布后立即同步行动计划
- 按月更新进展
- 90 天阶段报告
```

## 结果沟通

向全员公布时，遵循几条：
- **好坏都讲**：既讲做得好的（值得保护），也诚实讲短板。
- **讲清「听到了什么」**：用主题和代表性反馈，不只是分数。
- **承诺行动**：讲「我们要做什么」，而不是「我们会考虑」。
- **持续同步进展**：定期更新，见效就庆祝，没见效就承认并调整。

## 避免的坑

- **调研疲劳**：别发太多问卷。年度全面 + 季度脉冲足够。
- **只收集不行动**：最伤，直接导致下次回收率崩盘。
- **过度解读**：单题掉 0.1 分大概率是噪声，看 0.5 分以上的显著变化，并结合开放题理解「为什么」。
- **忽视少数声音**：即便只有 10% 的人感到被排斥，也是值得解决的问题；关注被抑制之外仍可展示的弱势分组。
